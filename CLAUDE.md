# بسطة فلافل (Falafel Stall) — iOS game

## Talk to the owner in Arabic
The owner (Saad) speaks Palestinian/Levantine Arabic. Always reply in Arabic, short and clear.
Be cost-conscious: no multi-agent workflows or parallel subagents unless explicitly asked. Work directly.

## What this is
SwiftUI iOS game (iOS 15.0+, Swift 5 language mode), project generated by XcodeGen from `project.yml`.
All UI text is Levantine Arabic, right-to-left. Display name: بسطة فلافل.

## Building
- There is no local iOS build on Windows. GitHub Actions (`.github/workflows/build-ipa.yml`, macOS runner)
  builds an unsigned IPA on every push to `main` (or a manual "Run workflow"), and publishes it as a
  GitHub Release (`build-N`). The owner installs that IPA.
- Compile errors appear in the Actions log of the "Build (unsigned)" step: search for `error:`.
- Keep the tree compiling before pushing to `main`; each push makes a release the owner may install.

## Art
- 3D icons: Microsoft Fluent Emoji 3D (MIT, license in `ThirdParty/`). 256 px PNGs, show at ≤ 85 pt.
- Keys are listed in `tools/art_keys.txt` (prefixes food_, ppl_, face_, bld_, veh_, ui_, ani_).
- Download all PNGs: `python tools/art/fetch.py` (manifest `tools/art/manifest.json`), then install only
  the keys the Swift code uses: `python tools/install_art.py <png_dir> --from-swift MyApp`.
- Never render emoji characters as `Text` in v3 screens; use `ArtIcon`.

## Conventions
- iOS 15 APIs only (no NavigationStack, no `.numericText`, no Observation framework).
- Saves are JSON in UserDefaults with tolerant decoding (every field defaulted) so updates never wipe saves.
- Developer credit "Developer: Saad" stays in settings.
